# Substack Workshop

A public workspace for collecting thoughts, developing essays, and keeping the drafts behind published Substack pieces.

The working rule is simple: capture first, organize when useful. Notes can stay fragmentary. A draft does not need to be complete to belong here.

## Where things live

- [Notes](notes/index.md): loose thinking, questions, fragments, and connections.
- [Drafts](drafts/index.md): drafts and placeholders imported from Substack.
- [Published](published/index.md): canonical copies and links for finished Substack posts.

## Workflow

1. Add ideas wherever they naturally fit in `notes/`.
2. When a thread becomes an article, create a draft and link any related notes.
3. Revise the article here, keeping its history in Git.
4. After publishing on Substack, add its URL and date and copy the final text into `published/`.

This repository is public. Raw notes and earlier committed versions are part of its public history.
